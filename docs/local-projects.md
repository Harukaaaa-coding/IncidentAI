# 本地项目只读调查

本地项目入口与模拟事故入口独立。它读取本机仓库、可选日志和健康响应，不需要先接 MCP；不运行被检查项目的测试、构建、脚本，不修改代码，不重启或回滚服务。

## 从页面接入 DeepSearch

1. 打开 IncidentAI 工作台，点击顶栏「本地项目」或「添加本地项目」。
2. 在添加窗口中点「填入 DeepSearch」。后端找到该本机项目时会填写建议值，不会自动添加。也可以手动填写绝对路径。
3. 检查项目名称与仓库目录。日志文件或目录、健康地址均可选；日志路径必须位于仓库内部，当前仅采集 `.log`、`.txt`、`.jsonl`、`.ndjson` 文件。没配置就明确显示未检查，不把缺失当作正常。
4. 点击「保存项目」，再点「验证连接」，确认可读取范围及健康地址是否可用。
5. 填写要调查的问题，点击「开始只读调查」。本轮默认不调用模型、不产生模型 API 费用。
6. 查看检查结果、发现、假设和限制。点击证据编号可展开原始脱敏内容及来源路径、行号。调查历史保存在 IncidentAI 数据目录，刷新页面仍可查看。

路径是 IncidentAI 服务所在电脑上的路径，不是浏览器所在设备的路径。浏览器不上传整个仓库，也没有伪造的文件系统选择器。请不要把整个用户主目录、凭据目录或无关日志作为项目范围。

调查问题用于记录目标；当前本地检查执行固定、安全的采集与规则，不等于通用 LLM Agent 已完成任意问题，也不能证明线上没有故障。没有运行真实测试、构建、生产指标或部署关联时，页面会保留限制，不宣称“测试通过”或“根因已确认”。

## 外部模型复核需要单独确认

完成本地检查后，可选择「预览外发内容」。预览接口仅在本地准备数据；不调用模型。

弹窗会显示实际模型、接收地址、字节数、内容摘要和本次完整请求内容。请人工检查脱敏结果；自动脱敏不能保证移除所有敏感信息。确认有权限分享后，手动勾选授权，再点击「授权并调用模型」。此步骤可能产生 API 费用，不授权则不发送。

授权绑定当前调查内容的摘要，不能复用于不同内容。打开页面、刷新、切换项目、读取历史以及查看已经保存的模型复核都不会自动发起新的模型调用。模型复核与本地事实区分展示，模型没有写入项目或生产操作工具。

## 入口与状态

- 顶栏「调查工作台」保留原有模拟场景、审批和恢复闭环；与真实项目无关。
- 顶栏「本地项目」展示真实项目读取结果；没有生产回滚按钮。
- 浏览器记住上次选择的本地项目和调查；后端记录才是调查历史的来源。
- 遇到服务不可用、路径不可读、没有模型配置或模型响应失败时，页面明确显示错误，不把失败渲染成通过。
